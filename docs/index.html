UI Design & Concept Architecture Showcase

Notice: This repository represents a design prototype and UI architecture implemented in Android Jetpack Compose & Material 3 Expressive. It showcases custom Canvas rendering (vinyl turntable disc, tonearm, circular progress rings), contextual app bar menus, download managers, and interactive screen routing. It is currently in the design & UI phase; a functional audio decoder engine (Media3/ExoPlayer local file scanner) is planned for future phases.

Crafted with Material 3 Expressive

A modern mobile architecture featuring canvas-drawn turntables, download managers, and contextual screen tooling.

album

Full-Screen Vinyl Turntable

Complete edge-to-edge modal sheet with concentric groove rings, tonearm needle, animated spinning disc, and Sleep Timer dial integration.

motion_photos_on

High-Attention Mini-Player

Floating pill with glowing border, mini bouncing equalizer waveforms, circular progress ring, and generous gesture bar clearance.

download

Offline Downloads Manager

Full Keeps screen management with Downloading sliders, speed meters, hold-to-select multi-selection, and finished batch archives.

search

Smart Search & CDN Selector

Recent searches, trending recommendations, simulated skeleton loading cards, and provider toggle (Spotify, YouTube Music, JioSaavn CDN).

text_fields

Typography & Appearance Subscreen

Interactive settings subscreen allowing instant switching between modern Outfit App Font and native Android system font.

more_vert

Contextual 3-Dot Top Bar Menus

Custom tailored menu actions per screen (Home library scanning, Music sorting, Keeps download pauses, and Search filters).
